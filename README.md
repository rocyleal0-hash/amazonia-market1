# Amazonia MARKET 🛒

Tu supermercado online en Coro, Falcón. Un proyecto e-commerce diseñado para ofrecer una experiencia de compra rápida, con catálogo de categorías, carrito y pedidos integrados por WhatsApp.

## 🚀 Enlace en Vivo
Puedes visitar la tienda funcionando en: [amazoniamarkett.com](https://amazoniamarkett.com/)

## 🛠️ Tecnologías Utilizadas
* **Frontend:** HTML5, CSS3, JavaScript.
* **Backend / Scripts:** Python (utilizado para la lógica y gestión de datos).
* **Hosting:** GitHub Pages / GitHub Repositories.

## 📌 Características
* Catálogo dinámico por categorías (Víveres, Charcutería, Carnicería, Bebidas, etc.).
* Franja de confianza y delivery.
* Modales interactivos para cantidades y selección por gramos.
* Conexión directa para procesar pedidos de forma ágil.
